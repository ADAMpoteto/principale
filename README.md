# Principale

データは Google スプレッドシート「Principale」から読み込みます。


## ページ
| ページ | 内容 |
|---|---|
| TOP | ニュース・次の試合・前の試合・直近5試合のフォーム・シーズン成績・順位表（抜粋）・トップ選手 |
| MATCHES | 日程と結果（大会で絞り込み）。試合ごとに「概要（試合経過・MOM・主要スタッツ）／スタッツ（両チーム比較）／ラインナップ（ピッチと評価）」 |
| STANDINGS | 順位表シートの表と、シーズンごとの順位 |
| STATS | 選手ランキング（得点・アシスト・平均評価・MOM・xG・キーパス・タックル…）と、チームスタッツ（1試合平均・成功率など） |
| PLAYERS | ポジション別の選手カード。選手ページに総合値・試合ごとの評価グラフ・総合値の推移グラフ・試合ログ・シーズン別成績 |
| TRANSFERS | 加入・退団と、支出・収入・収支 |
| CLUB | クラブ概要・通算成績・タイトル・通算ランキング・シーズンごとの順位 |

画面上部の「シーズン」で、全ページのシーズンを切り替えられます（「全シーズン」で通算）。

## スプシのシート
| シート | 1行に入れるもの |
|---|---|
| 設定 | クラブ名・リーグ・クラブの方針・スローガン。右側に各シートの書き方 |
| 試合 | 全部の試合（自分も他クラブも）。ホーム／アウェイ形式。順位表はここから自動 |
| チームスタッツ | 自分の試合×チーム（自分・相手で2行）。試合後「スタッツ」画面の数字 |
| 出場選手 | 自分の試合×選手（相手も入れられる）。得点・アシスト・MOMはここから自動 |
| 試合経過 | ゴール・警告・交代など（なくてもOK） |
| 選手 | 自分のクラブの選手（出身：ユース／初期メンバー）。「主将」列に主将だったシーズン（例：2026-27）を入れる |
| 選手の推移 | 総合値などの記録。レンタル中は「レンタル先」とそこでの成績も |
| 移籍 | ユース昇格・売却・レンタル移籍・復帰など |
| リスト | クラブ（略称・国・リーグ）と、大会・ポジションなどの選択肢 |

- 「チームスタッツ」「出場選手」「試合経過」は、試合シートと同じ**日付**でつながります。
- 入れるのは「回数・数」だけ。成功率・1試合平均などはサイトが計算します。
- シーズンごとのリーグ・順位・獲得タイトルは、試合シートと順位から自動で出ます。
- 分からない項目は空欄でOK。空欄の項目はサイトに出ません。
- 詳しくはスプシの「説明」シートを見てください。

### スプシのつなぎ方
スプシは「ファイル → 共有 → ウェブに公開（ドキュメント全体）」にしておきます。
読み込めないときは「共有 → リンクを知っている全員（閲覧者）」にもしてください。スプシのIDは `js/config.js` の先頭にあります。

## 画像の置き方
GitHub のこのリポジトリに、決まったフォルダ・決まった名前で画像を置くだけです。

| 何 | 置き場所 | ファイル名 |
|---|---|---|
| 選手の写真 | images/player/ | スプシの「名前」と同じ（例：`高橋 蒼.png`） |
| クラブのロゴ | images/logo/ | クラブシートの「クラブ」と同じ名前 |
| 自分のクラブのロゴ | images/logo/ | 設定シートの「クラブ名」と同じ（今は `Principale.png`） |

- 拡張子は .png / .webp / .jpg のどれでもOK。画像がない選手・クラブは頭文字で表示されます。

## ファイルの構成

`index.html` が上から順に読み込みます。順番を入れ替えると動かなくなるので注意してください。

| ファイル | 中身 |
|---|---|
| `js/config.js` | 設定（スプシのID・シート番号） |
| `js/util.js` | 小物（文字・日付・数値）とスプシの読み込み |
| `js/data.js` | データの読み込みと整形 |
| `js/parts.js` | 画像・エンブレム・クラブ情報など共通の部品 |
| `js/stats.js` | 集計（選手・チーム・ランキング項目） |
| `js/charts.js` | グラフとツールチップ |
| `js/components.js` | 画面のパーツ（見出し・試合の行・順位表・試合カード） |
| `js/news.js` | ニュース（記録・記事・画像の自動生成） |
| `js/home.js` | ホーム |
| `js/matches.js` | 試合日程・結果、試合詳細、メンバー |
| `js/table-stats.js` | 順位表・記録 |
| `js/players.js` | 選手・スタッフ一覧、選手ページ、スタッフページ |
| `js/club.js` | ヒストリー・移籍情報・クラブ |
| `js/main.js` | ページの切り替えと起動 |
| `css/base.css` | 基本（色・文字・共通パーツ） |
| `css/layout.css` | ヘッダー・メニュー・フッター・ページ上部の帯 |
| `css/home.css` ほか | 各ページの見た目（home / news / matches / table / stats / players / club） |
| `css/tweaks.css` | ほかのファイルの指定を上書きする調整（最後に読み込む） |
