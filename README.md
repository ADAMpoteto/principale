# Principale

クラブ公式サイト風の記録サイト。データは Google スプレッドシート「Principale」から読み込みます。

## スプシのつなぎ方
スプシを「共有 → リンクを知っている全員（閲覧者）」にすれば、そのまま表示されます。
（読み込みが不安定なときは「ファイル → 共有 → ウェブに公開（ドキュメント全体）」して、そのURLを app.js の `PUB_URL` に貼る）

## スプシのシート
| シート | 1行に入れるもの |
|---|---|
| 試合 | 1試合。得点・失点を空欄にすると「次の試合（NEXT MATCH）」になる |
| チームスタッツ | 1試合×1チーム（自分・相手で2行）。FC27の「スタッツ（Match Facts）」画面の項目。空欄の項目は出場選手の合計を使う |
| 出場選手 | 1試合×1選手（自分も相手も）。FC27の「パフォーマンス」画面の項目（評価・ライン突破・GKのセーブ種類など） |
| 試合経過 | ゴール・警告・交代などの出来事 |
| 選手 / 移籍 / シーズン / 順位表 / 設定 | プロフィール・移籍・シーズンのまとめ・最終順位・クラブ名など |

- 試合以外の「試合の記録」は、試合シートと同じ日付でつながります。
- スプシには「回数・数」だけを入れます。成功率・シュート決定率・セーブ率・1試合平均などはサイトが計算します。
- 分からない項目は空欄でOK。空欄の項目はサイトに出ません。

## 画像の置き方
GitHub のこのリポジトリに、決まったフォルダ・決まった名前で画像を置くだけです。スプシに画像を貼る必要はありません。

| 何 | 置き場所 | ファイル名 |
|---|---|---|
| 選手の写真 | images/player/ | スプシの「名前」と同じ（例：`高橋 蒼.png`。スペースなし `高橋蒼.png` でもOK） |
| 相手クラブのロゴ | images/logo/ | 試合シートの「相手」と同じ（例：`Aldebaran FC.png`） |
| 自分のクラブのロゴ | images/logo/ | `Principale.png` |

- 拡張子は .png / .webp / .jpg のどれでもOK。
- 名前とファイル名を変えたいときは、選手シートの「写真」にファイル名（例：`takahashi.png`）を書く。
- 画像がない選手・クラブは、頭文字で表示されます。
- 写真は縦長（4:5）・横400px くらいがきれいに収まります。

### GitHub での上げ方（スマホのブラウザでもできます）
1. リポジトリを開いて `images/player` フォルダに入る
2. 「Add file」→「Upload files」
3. 画像を選んで「Commit changes」
4. 1〜2分でサイトに反映（反映されないときはページを再読み込み）
