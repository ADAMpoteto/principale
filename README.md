# Principale

FC27 監督キャリアの記録サイト。データは Google スプレッドシート「Principale」から読み込みます。

## スプシのつなぎ方
スプシを「共有 → リンクを知っている全員（閲覧者）」にすれば、そのまま表示されます。
（読み込みが不安定なときは「ファイル → 共有 → ウェブに公開」して、そのURLを app.js の `PUB_URL` に貼る）

## 画像の置き方（名前と同じファイル名にするだけ）
| 何 | 置き場所 | 例 |
|---|---|---|
| 選手の写真 | images/player/ | images/player/上田 綺世.png |
| 相手クラブのロゴ | images/logo/ | images/logo/鹿島.png（試合シートの「相手」と同じ名前） |
| 自分のクラブのロゴ | images/logo/ | images/logo/Principale.png |

- 拡張子は .png / .webp / .jpg のどれでもOK。名前のスペースはあってもなくてもOK。
- 画像がない選手・クラブは頭文字の丸で表示されます。
- 選手写真は正方形・横400px くらいの .webp にすると軽くてきれいです。

## スプシのシート
| シート | 1行に入れるもの |
|---|---|
| 試合 | 1試合。得点・失点を空欄にすると「これからの試合（NEXT MATCH）」になる。動画欄にYouTubeのURLを入れると試合ページで再生できる |
| チームスタッツ | 1試合×1チーム（自分・相手で2行）。フォーメーション・支配率・シュートなど |
| 出場選手 | 1試合×1選手（自分も相手も）。先発の11人がスタメン図に並ぶ。評価・得点・アシストなど |
| 試合経過 | ゴール・警告・交代などの出来事 |
| 選手成績 | 1選手×1シーズン（空欄なら出場選手シートから自動で計算） |
| 選手 / 移籍 / シーズン / 順位表 / 設定 | プロフィール・移籍・シーズンのまとめ・最終順位・クラブ名など |

試合以外の「試合の記録」は、試合シートと同じ日付でつながります。

## ニュース
試合・移籍・シーズンのシートの行から自動で作ります（画像も自動）。
